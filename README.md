# Excel Data Analysis Project

## Project Overview

This project is a beginner friendly data analysis project completed using Microsoft Excel.

The goal of the project was to analyze sales data, calculate key business metrics, identify trends, and present the findings through an interactive dashboard.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Excel Charts
* Excel Formulas
* Data Cleaning
* Data Visualization
* power BI
## Key Analysis

The project analyzes:

* Total Net Sales
* Total Profit
* Profit Margin
* Sales and Profit by Product
* Net Sales by Region
* Monthly Net Sales Trend
* New vs Returning Customers
* Net Sales by Payment Method

## Key Findings

* Total Net Sales: ₦448,326,026
* Total Profit: ₦102,667,126
* Profit Margin: 22.9%
* Bank Transfer was the highest-performing payment method.

## Project Outcome

This project helped me strengthen my skills in Excel data analysis, data visualization, KPI calculation, and communicating business insights from data.
